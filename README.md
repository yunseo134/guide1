# GitHub 시험 코치 노트

정적 HTML 기반 시험 대비 자료입니다.

## 로컬에서 보기
`index.html`을 브라우저로 열면 됩니다.

## GitHub Pages에 올리기
1. 새 저장소를 만들거나 기존 저장소에 이 파일들을 업로드합니다.
2. Settings → Pages
3. Source를 `Deploy from a branch`로 선택
4. Branch를 `main` / `/root`로 선택
5. 저장 후 제공되는 Pages 주소로 접속합니다.

## 내도메인.한국 등에 연결하기
정적 호스팅이 가능한 곳에 `index.html`, `assets/` 폴더를 업로드하면 됩니다.
